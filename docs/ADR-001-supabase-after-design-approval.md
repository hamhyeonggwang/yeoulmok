# ADR-001 — Supabase는 디자인 승인 후 연결한다

- 상태: Accepted
- 단계: Design Preview
- 결정일: 2026-09-13

## Context

여울목 홈페이지는 현재 고객에게 디자인 초안을 제시하고 시각 방향과 정보구조를 승인받는 단계다. 기능 연결을 먼저 진행하면 디자인 변경 시 데이터 계층과 화면 계층을 동시에 수정해야 해 재작업 비용이 커진다.

## Decision

1. 디자인 검토 단계에서는 정적 mock data만 사용한다.
2. 기능 연결은 디자인 승인 이후 착수한다.
3. 공지사항/고시공고의 운영 DB는 Supabase PostgreSQL을 사용한다.
4. 첨부파일은 Supabase Storage를 사용한다.
5. 기관소개, 프로그램, 후원안내, 위치/문의 기본정보는 초기에는 정적 content layer로 유지한다.
6. 관리자 화면과 Supabase Auth는 별도 후속 범위로 분리한다.

## Consequences

- 디자인 변경과 데이터 구현을 분리할 수 있다.
- 고객은 기능 미완성에 방해받지 않고 화면/콘텐츠 구조를 검토할 수 있다.
- 디자인 승인 이후 DB schema와 UI contract를 고정해 구현할 수 있다.
- 현재 시안의 mock 게시물은 실제 기관 데이터로 오인되지 않도록 표시한다.
